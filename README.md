# ZO Hotel — Candolim, Goa

Single-page website for ZO Hotel, a beachfront hotel in Candolim, North Goa.

## Contents

- `index.html` — the complete site. All photographs are embedded as data URIs,
  so the page runs standalone with no other files and no build step.
- `*.jpg` — the source photographs, kept here so the page can be re-edited.

## Built with

Plain HTML, CSS and vanilla JavaScript. No framework, no dependencies.
Poppins is loaded from Google Fonts; everything else is self-contained.

## Before this goes to a real audience

The following content is placeholder and must be replaced with real details:

- Phone, WhatsApp, email and street address in the footer
- The Goa Tourism registration number in the footer bar
- The guest reviews and the review counts
- The booking form, which validates dates but is not connected to a booking engine
